Security & Privacy Policy

1. Progressive Web App & Offline Cache: Anime Navigator uses Service Worker technology to cache the application shell and your watchlist. All your anime titles, posters, and links remain securely stored inside your device's browser (`localStorage` and Cache API).

2. Zero Data Collection & Tracking: Anime Navigator does NOT use analytics, cookies, tracking pixels, advertisement networks, or user fingerprinting scripts.

3. External Web Links: Saved watch links redirect to third-party external websites in a new tab with strict `noopener,noreferrer` tab isolation.

4. Data Backup & Control: You can export and import your complete watchlist JSON anytime using the Data manager to sync between your phone, tablet, and PC.

5. Security Reporting: Vulnerabilities or security concerns can be responsibly disclosed through our official repository issue tracker.

Terms of Use

1. Personal Navigation Tool: Anime Navigator is a personal bookmark tool and web navigator. It does NOT host, store, stream, or distribute any anime video files or media content.

2. User Responsibility: Users are responsible for the links they choose to save and launch. You agree not to intentionally save malicious or illegal URLs.

3. Third-Party Content: Third-party streaming websites are independent entities. Anime Navigator has no control over external content, availability, or third-party site safety.

4. Local Storage Disclaimer: Data is saved in browser `localStorage`. Clearing browser data or using private/incognito mode may result in local data loss. Use the Export Backup feature to regularly keep a copy of your bookmarks.

Anime Navigator User Guide

Complete documentation & pro tips for managing your anime watchlist offline and across devices.

1. Quick Add Bookmarks

Click + Add Anime in the header navigation. Enter the title, an image URL (supports any HTTPS poster image), select your category, and paste your direct watch link.

2. Direct Stream Launching

Click any anime card anywhere to directly launch your saved stream in a secure new tab. To edit title, status, poster, or stream URL, click the pencil icon.

3. Category Management

Organize your titles into 4 focused categories: Watching, Going to watch, Ongoing-follow-up, and Completed. Badges in the header display real-time counts.

4. Progressive Web App (PWA) & Offline Access

Install Anime Navigator to your home screen or desktop taskbar. The application shell is pre-cached with service workers, allowing offline access to your full catalog anytime.

5. JSON Data Backup & Sync

All data stays in your browser's private local storage. Use Backup & Restore in the footer to export your entire watchlist to a portable JSON file or import onto another device.

6. Live Dynamic Wallpapers

Click the Wallpaper icon () in the header to cycle through curated high-definition anime background themes. Your selection persists automatically.

7. Keyboard Shortcuts

Esc closes any open dialog or modal. Fast filtering is available instantly via the search bar with live character matching.
