Security & Privacy Policy

1. Local Storage Only: All anime titles, poster image URLs, category statuses, and watch links are stored locally in your browser (`localStorage`). No server database, user accounts, or cloud storage exist.

2. Zero Data Collection & Tracking: Anime Navigator does NOT use analytics, cookies, tracking pixels, advertisement networks, or user fingerprinting scripts.

3. External Web Links: Saved watch links redirect to third-party external websites in a new tab with strict `noopener,noreferrer` tab isolation. External websites operate independently under their own privacy policies.

4. Data Control & Deletion: You have full control over your data. You can delete individual entries using the edit menu or clear all saved data anytime by clearing your browser's site data.

5. Security Reporting: Vulnerabilities or security concerns can be responsibly disclosed through our official GitHub repository issue tracker.

Terms of Use

1. Personal Navigation Tool: Anime Navigator is a personal bookmark tool and web navigator. It does NOT host, store, stream, or distribute any anime video files or media content.

2. User Responsibility: Users are responsible for the links they choose to save and launch. You agree not to intentionally save malicious or illegal URLs.

3. Third-Party Content: Third-party streaming websites are independent entities. Anime Navigator has no control over external content, availability, or third-party site safety.

4. Local Storage Disclaimer: Data is saved in browser `localStorage`. Clearing browser data or using private/incognito mode may result in local data loss.
